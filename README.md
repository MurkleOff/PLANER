# ⚡ Дисциплина & Фокус (Discipline & Focus Dashboard)

Персональная система отслеживания привычек, планов и дисциплины на русском языке.  
Построена на **React 18 + Vite + Tailwind CSS + Lucide Icons** с гибридным хранилищем (**Offline-first LocalStorage + Supabase Cloud Sync**).

---

## 🚀 Быстрый запуск

### 1. Запуск в режиме разработки:
```bash
npm run dev
```
После запуска откройте в браузере: `http://localhost:5173`

### 2. Сборка для продакшена:
```bash
npm run build
```

## 📱 Установка на смартфон (PWA)
Приложение полностью настроено как прогрессивное веб-приложение (PWA):
1. Откройте развёрнутое приложение в мобильном браузере (Safari на iPhone или Chrome на Android).
2. Нажмите кнопку меню «Поделиться» (в Safari) или три точки (в Chrome).
3. Выберите **«На экран «Домой»» (Add to Home Screen)**.
4. Приложение появится на рабочем столе как отдельная нативная иконка без адресной строки браузера.

## ☁️ Подключение бесплатного облака Supabase (Синхронизация ПК и смартфона)

1. Зарегистрируйтесь бесплатно на [supabase.com](https://supabase.com) и создайте новый проект.
2. В боковом меню откройте **SQL Editor** &rarr; **New query**.
3. Вставьте следующий SQL-скрипт и нажмите **Run**:

```sql
-- Создание таблицы синхронизации
create table if not exists public.panel_sync (
  id text primary key,
  payload jsonb not null,
  updated_at timestamptz default timezone('utc'::text, now()) not null
);

-- Включение доступа по anon key
alter table public.panel_sync enable row level security;

create policy "Доступ к синхронизации"
  on public.panel_sync
  for all
  using (true)
  with check (true);
```

4. Скопируйте из настроек проекта Supabase (Project Settings &rarr; API):
   - `Project URL` &rarr; вставьте в поле `SUPABASE_URL` в приложении
   - `anon public key` &rarr; вставьте в поле `SUPABASE_ANON_KEY`
   - Придумайте любое своё кодовое слово в поле `Sync ID` (например, `my-secret-discipline-code`).
5. Нажмите **«Проверить подключение»** &rarr; **«Сохранить и выгрузить (Push)»**.
6. Откройте приложение на телефоне, введите тот же `Sync ID` и нажмите **«Загрузить с облака (Pull)»**. Теперь ваши устройства синхронизированы!

## 🌐 Деплой в 1 клик на Vercel

1. Загрузите репозиторий на свой GitHub.
2. Откройте [vercel.com](https://vercel.com) &rarr; **Add New Project** &rarr; выберите ваш репозиторий.
3. Vercel автоматически распознает Vite и конфигурацию из готового файла `vercel.json`.
4. Нажмите **Deploy**. Через 30 секунд панель будет доступна по бесплатному публичному адресу `https://ваш-проект.vercel.app`.

## 🛠 Ключевые возможности

- **Заряд дня (0–100%):** взвешенная формула: 60% привычки + 40% «3 Главные задачи дня». При 100% срабатывает торжественный звуковой аккорд и конфетти!
- **Умный расчёт серий (Smart Streak):** для недельных квот `N/7` (например, силовая 4/7) дни отдыха не сбрасывают серию, пока математически возможно закрыть квоту до конца недели.
- **Deep Work Таймер:** расчет времени по системным часам (не сбивается при переключении вкладок), синтезатор звука тибетского гонга через Web Audio API (без внешних mp3) и браузерные пуш-уведомления.
- **Матрица недели (Пн–Вс):** календарная привязка к реальным датам, фильтрация по категориям, интерактивная смена отметок в 1 клик.
- **Интерактивный график недели (SVG):** переключение между плавной линией Безье и столбчатой диаграммой с подробными всплывающими подсказками.
- **Резервная копия:** экспорт/импорт всей базы в `.json` файл и через буфер обмена.
